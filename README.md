# CSCS agent skills repo

This is an unofficial collection of [agent skills](https://agentskills.io/home) used or created by and for CSCS staff and users.

There's no hard constraint on what type of skills belong in the repo, but particularly interesting are skills that are specific to interacting with CSCS resources, docs, etc.
All other kinds of skills are still welcome both as a reference and inspiration to others.
As a soft constraint on whether you should open a PR with your skill is that it should've been useful to you at least a few times.
If you've asked your agent to generate a one-off skill for you and you've never or only once tried the skill, it's probably not ready for this repo yet.

## Structure

Add skills to the `skills/` subdirectory.
If appropriate, add a `README.md` for human consumption explaining what problem the skill is trying to solve and why this form of the skill is useful.
